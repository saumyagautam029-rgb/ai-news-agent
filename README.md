# AI News Agent (Zero-Cost Local Setup)

A smart AI news agent built for the YGF NGO internship evaluation. It fetches the latest news via DuckDuckGo, cross-validates source credibility and facts using a local open-source LLM (Ollama / Llama 3), and generates tailored social media posts for LinkedIn, Twitter/X, and Instagram.

## Prerequisites
1. Python 3.8+ installed.
2. [Ollama](https://ollama.com/) installed and running locally with Llama 3 (`ollama run llama3`).
